# CultureGSite

Site de culture générale : 9 vignettes thématiques (santé, géopolitique, économie, physique, informatique, mathématiques, études, philosophie, langue française). Chaque vignette ouvre une page de thème qui liste et résume les documents, pages web et vidéos associés, avec le statut de lecture de chaque source.

## Fichiers

- `index.html` : le site complet (HTML, CSS et JavaScript dans un seul fichier, sans dépendance à installer). La navigation entre thèmes et fiches repose sur le fragment d'URL (`#sante`, `#etudes-salaires`, etc.).

## Utilisation

Ouvrir `index.html` dans un navigateur, ou publier le dépôt avec GitHub Pages (branche `main`, dossier racine).
